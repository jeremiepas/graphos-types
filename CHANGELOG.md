# Changelog for graphos-types

## 0.1.0.0 — 2026-09-14

First standalone release. Extracted from the `Graphos` monorepo
`Graphos.Domain.Types.*` modules.

- `Graphos.Types.Node`: `Node`, `NodeId`, `NodeKind`.
- `Graphos.Types.Edge`: `Edge`, `EdgeId`, `EdgeKind`.
- `Graphos.Types.Graph`: `Graph`, `GraphStats`.
- `Graphos.Types.Analysis`: `Analysis`, `AnalysisResult`, `AnalysisConfig`,
  `AnalysisScope`, `AnalysisStatus`, `AnalysisError`.
- `Graphos.Types.GraphFile`: `GraphFile`, `GraphFileEntry`.
- `Graphos.Types.Writer`: `Writer`, `WriterOutcome`.
- `Graphos.Types.Ingest`: `IngestRequest`, `IngestResponse`, `IngestFailure`,
  `IngestBatch`, `IngestStats`.
